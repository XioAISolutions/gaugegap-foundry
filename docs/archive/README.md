# Archived documents

These are **unmaintained historical snapshots** — early sprint notes, deployment
checklists, and status summaries kept only for provenance. Their wording predates the
current claim-boundary discipline and may contain overclaim language ("proof", "ready
for publication", etc.) that the project **no longer uses or endorses**.

The authoritative, claim-bounded statements of what this repository does — and does not
— establish live in the top-level `README.md`, `docs/ARCHITECTURE.md`, and each
hypothesis's `claim_boundary`. Nothing here is an active claim.

The claim-boundary and research-maturity audits deliberately exclude this directory for
that reason.
