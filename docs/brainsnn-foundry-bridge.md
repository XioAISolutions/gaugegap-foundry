# BrainSNN Foundry Bridge

GaugeGap Foundry can serve as a research-facing proof layer for BrainSNN-style
content intelligence: it demonstrates how a claim is made finite, measured,
audited, visualized, and bounded before it is used in public communication.

## Positioning

BrainSNN is a decision engine for brand content.  GaugeGap is the technical
research showcase that supports the same operating principle in harder domains:
do not publish a strong claim until the evidence, boundary, and failure mode are
visible.

The bridge is not that brand-content scoring and quantum physics are the same
problem.  The bridge is the workflow:

- define the claim;
- define the finite observable;
- define the control;
- emit evidence;
- fail closed when a boundary breaks;
- show the result in a form a human can inspect.

## Research Tracks As Content Checks

- GaugeGap/FlowGap/CurveRank: finite scientific benchmarks with explicit
  non-solution boundaries.
- UQT Forge: exact finite algebra controls and reversibility gates.
- Compactification Forge: hidden-mode visibility under finite cutoff assumptions.
- Perception Forge: fitness-interface vs truth-coded strategy checks under
  resource limits.
- Menger Sponge Forge: fractal/topological intuition gap with finite-stage
  arithmetic.
- Entanglement Forge: non-classical correlation with no-signaling guardrails.
- Quantum Gap Functional: one bounded synthesis score that turns zero if the
  validation barrier fails.

## Claim Boundary

Allowed language:

- GaugeGap is a research showcase for verification-first workflows;
- the same fail-closed style can inform BrainSNN content preflight;
- Foundry artifacts can become educational, research, or credibility material.

Avoid:

- BrainSNN proves physics claims;
- GaugeGap validates marketing claims automatically;
- Quantum Gap is a universal truth score;
- cognitive, brand, and quantum domains are interchangeable.

## Export

The repo can export a compact handoff package:

```bash
foundry run brainsnn-showcase
```

or directly:

```bash
python scripts/export_brainsnn_showcase.py --output-dir site/brainsnn-gaugegap-showcase
```

The output contains `showcase.json` and `showcase.md` cards for BrainSNN-facing
research pages or content preflight examples.  The cards preserve each artifact's
observable and claim boundary.
