# Jacobian Aftershock: a compact four-sheet Keller map

The first Counterexample Forge benchmark reproduced and structurally reconstructed
the public three-variable Jacobian counterexample. This follow-on track asks a
narrower optimization question inside the recently published weighted-lift
mechanism:

> Can the cubic-seed, four-sheet member be made substantially smaller in expanded
> polynomial form while retaining exact certificates?

The answer in the declared normalization is yes.

## Result

Set

```text
u = 1 + xy
gamma = 1 + x^2 z
```

and define the polynomial map `H : C^3 -> C^3` in compact weighted form by

```text
H1 = [2u + u^2(9u^2 gamma^2 - 16u gamma + 5)] / x^2
H2 = [1 + u(6u^2 gamma^2 - 12u gamma + 5)] / x
H3 = x gamma
```

The apparent quotients cancel identically. The exact verifier stores the expanded
polynomials directly, so no division or numerical sampling enters certification.

The expanded coordinate monomial counts are

```text
(13, 10, 2)  ->  25 total monomials
```

with ordinary total degrees

```text
(12, 11, 4).
```

Exact symbolic differentiation gives

```text
det(JH) = 2
```

identically.

## Short collision certificate

Two distinct rational points share one image:

```text
H( 1/3, -10/3,  18) = (-20/27, -2/9, 1)
H(-1/3,  14/3, -36) = (-20/27, -2/9, 1)
```

That finite identity alone proves that this particular constant-Jacobian map is
not injective.

## Exact four-point fiber

The same map also has a fully rational four-point fiber:

```text
H(  9/2, -2/9, -748/19683) = (0, 2/9, 28/27)
H( -28/5,  2/7,   -50/1323) = (0, 2/9, 28/27)
H(   4/3,    0,        -1/8) = (0, 2/9, 28/27)
H( -7/30,    6,        -100) = (0, 2/9, 28/27)
```

All arithmetic is rational and all four source points are pairwise distinct.

## Where the map comes from

Use the normalized cubic seed family

```text
p_g(w) = (2 + g/2)w + (-3 - 3g/2)w^2 + g w^3.
```

Every member satisfies

```text
p_g(0) = 0
p_g(1) = -1
integral_0^1 p_g(w) dw = 0.
```

The weighted-lift normalization is singular at `g=4`. At `g=0`, the cubic term
vanishes and the seed drops to degree two. The compact map is generated by

```text
g = 6
p_6(w) = 6w^3 - 12w^2 + 5w
p_6'(1) = -1
```

and that last slope makes the `xy` term in `gamma` disappear, producing
`gamma = 1 + x^2z` and a large cancellation in the expanded map.

## Exact family-minimum certificate

The generic normalized cubic member has `33` expanded monomials. Every expanded
coefficient numerator is a polynomial of degree at most three in `g`. Factoring
those numerators over the rationals gives this decisive ledger:

```text
factor g      occurs in 17 coefficient numerators
factor g - 6  occurs in  8 coefficient numerators
every other irreducible factor occurs in exactly 1 numerator
```

The `g=0` root is excluded from the four-sheet problem because it lowers the seed
degree. Therefore `g=6` is the unique valid parameter with eight simultaneous
coefficient cancellations:

```text
33 generic monomials - 8 cancellations = 25 monomials.
```

This is a global result inside the explicitly normalized cubic weighted-lift
family, not merely a finite brute-force observation. A redundant exact search of
all reduced rationals with numerator and denominator at most `64` independently
returns only `g=6`.

## Claim boundary

This track establishes exact identities and a monomial-count optimum in one
specified normalization. It does **not** establish that this map is the globally
smallest Keller counterexample under arbitrary polynomial coordinate changes.
It does not settle the separate two-dimensional Jacobian problem. A targeted web
search did not locate this exact seed or expanded map, but that is not a proof of
historical novelty; the evidence therefore remains labelled `DERIVED_EXACT` with
novelty status `UNESTABLISHED` pending specialist literature review.
